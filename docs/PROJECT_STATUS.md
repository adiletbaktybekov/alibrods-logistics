### 2. Выполненные задачи Phase 2 & 2.1 (Client Portal & Audit)
- [x] Создан интерфейс личного кабинета селлера:
  - `/login` — вход по Email/телефону с безопасными cookie.
  - `/register` — регистрация компании, контактов и ИНН.
  - `/dashboard` — KPI-счётчики (всего, в обработке, завершено), приветствие, последние заказы.
  - `/orders` — реестр заявок с фильтрами по статусам и поиском по `ABL-...`.
  - `/orders/new` — оформление заявки с динамической фильтрацией складов по расписанию дня недели.
  - `/orders/[id]` — карточка заявки, таймлайн статусов, блок фотоотчётов, запрет редактирования.
  - `/profile` — профиль компании, выбор склада по умолчанию, интеграция Telegram.
- [x] **Исправлен каталог складов (строго 12 подтверждённых объектов)**:
  - **Ежедневно**: Коледино, СК Вешки, Подольск, Подольск 4, ВБ Щербинка, Озон Щербинка, Озон Гривно.
  - **Пн / Ср / Пт**: Радумля, Обухово.
  - **Вт / Чт / Сб**: Чашниково, Чехов 1, Чехов 2.
  - Удалены все посторонние склады и вымышленные адреса.
- [x] **Динамическая доступность складов по дате**:
  - Клиент выбирает дату $\to$ отображаются только работающие в этот день склады.
  - Реализована серверная валидация: невозможно отправить заявку на неработающий склад.
  - Защита от смещения часовых поясов при вычислении дня недели.
- [x] **Очистка полей заявки**:
  - Обязательные поля: Дата доставки, Склад, Количество паллет, Количество коробок.
  - Комментарий необязательный.
  - Расчётный объём ($м^3$) и неподтверждённые поля удалены из интерфейса.
- [x] **Синхронизация статусов (11 реальных статусов процесса)**:
  - `CREATED` (Создана)
  - `PENDING_CONFIRMATION` (Ожидает подтверждения менеджера)
  - `CONFIRMED` (Подтверждена)
  - `ASSIGNED_TO_DRIVER` (Назначен водитель)
  - `ACCEPTED_BY_DRIVER` (Водитель принял заявку)
  - `PICKED_UP` (Забрана у клиента)
  - `IN_TRANSIT` (В пути)
  - `DELIVERED_TO_WAREHOUSE` (Прибыла на склад)
  - `ACCEPTED_BY_MARKETPLACE` (Принята маркетплейсом)
  - `COMPLETED` (Завершена)
  - `REJECTED_BY_MANAGER` (Отклонена менеджером)
  - `CANCELLED` (Отменена)
- [x] **Разграничение прав и защита от IDOR**:
  - Клиент видит исключительно свои заказы (`assertOrderAccess`).
  - У клиента изъято право на самостоятельное редактирование и смену статусов.
- [x] **Готовность к Google Sheets**:
  - В модель `Order` добавлены поля `deliveryCostAmount` и `currency`.
  - Подготовлен контракт получения стоимости по `orderNumber` из Google Sheets с сохранением PostgreSQL как источника правды.
