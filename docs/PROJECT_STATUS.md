## 3. Открытые вопросы и архитектурные решения для Phase 2

1. **Поставщик PostgreSQL**:
   - Рекомендуется согласовать провайдера управляемой базы данных (Managed PostgreSQL в Yandex Cloud, Timeweb Cloud, Supabase или самостоятельный хостинг на выделенном VPS).
2. **Файловое хранилище для фотоотчётов (S3)**:
   - Для фотографий приёмки и сдачи груза на склад маркетплейса потребуется S3-совместимое объектное хранилище (MinIO, Yandex Object Storage или Selectel).
3. **Регламент Telegram-ботов**:
   - Согласование интерфейса Telegram-бота водителя (кнопки смены статусов рейса, отправка локации, прикрепление фото).
4. **Структура синхронизации Google Sheets**:
   - Определение перечня колонок и триггеров двусторонней синхронизации таблиц логистов.
